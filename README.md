# Why-are-we-here
## Essay Outline
1. Why Learn Programming?
AI can generate code, but designers still need programming knowledge to understand, evaluate, and use it correctly.
2. My Experience as a Game Designer
AI helps me turn gameplay ideas into prototypes, but I still need to translate design ideas into programming logic before AI can effectively help me.
3. Programming in the Age of AI
AI changes how we use programming rather than making programming knowledge unnecessary.
## Core Idea: ##
AI generates code → I need to understand and judge it → programming fundamentals help me turn design ideas into things AI can actually build.
